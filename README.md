# رسا پرامپت (rasaprompt)

کتابخانه و بازار پرامپت فارسی‌محور (فارسی، عربی، انگلیسی) برای کاربران، کدنویس‌ها و حرفه‌ای‌ها، با اجرای پرامپت در سایت، ربات تلگرام و بله، پنل مدیریت درون ربات و استودیوی محتوای اینستاگرام. طراحی‌شده برای **شرکت یک‌نفره** با عامل‌های هوش مصنوعی.

مرجع خارجی: [prompts.chat](https://github.com/f/awesome-chatgpt-prompts) (کد MIT، محتوای CC0). جزئیات و ماتریس هم‌ترازی: `docs/17-reference-platform.md`.

## شروع سریع
```bash
cd app
npm install
cp .env.example .env
npm run catalog
npm run dev          # http://localhost:3000/fa
npm test             # ۳۸ تست
```
راهنمای کامل: `docs/18-local-setup-and-deploy.md`.

## چه چیزی آماده است
| بخش | وضعیت |
|---|---|
| سایت سه‌زبانه (RTL/LTR، تیره/روشن) | ✅ خانه، کتابخانه با فیلتر، صفحه‌ی پرامپت، اجرا، ذخیره‌ها، منابع |
| محتوا | ✅ ۲٬۴۹۰ پرامپت از منابع مجاز + ۱۶ تألیفی فارسی + ۱۳۸ عنوان فارسی |
| اجرای پرامپت در سایت | ✅ پخش زنده، سه رده‌ی مدل، اعتبار مصرفی، کد اعتبار (حالت mock تا اتصال سرویس‌دهنده) |
| ربات تلگرام و بله | ✅ جست‌وجو، پرطرفدار، حوزه، روز، تصادفی، زبان |
| سوپرادمین درون ربات | ✅ منابع (تشخیص لایسنس)، کاتالوگ، عامل‌ها، صف، کد اعتبار، ارسال همگانی، استودیو |
| استودیوی اینستاگرام | ✅ کپشن، کاروسل PNG، ریلز MP4 |
| عامل‌ها | ✅ ۲۰ تعریف در `agents/` |
| پایپ‌لاین‌ها | ✅ تست چندمدلی، بومی‌سازی، ترند، واردسازی منابع |
| حساب کاربری، درگاه پرداخت، ثبت پرامپت کاربران | ⏳ نقشه‌ی راه (docs/17، docs/13) |

## ⚠️ پیش از راه‌اندازی
1. کلید API که در گفت‌وگو ارسال شد را باطل کنید و کلید تازه را فقط در `app/.env` بگذارید.
2. نام برند و دامنه‌ی نهایی را انتخاب کنید (ADR-002، ADR-016).
3. اینماد و درگاه را شروع کنید؛ تا آن زمان با کد اعتبار بفروشید (docs/14).
4. محدودیت‌های فعلی: `docs/living/LIMITATIONS.md`.
