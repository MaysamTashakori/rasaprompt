# ربات‌های تلگرام و بله + پنل سوپرادمین

## معماری
```
bots/core.ts      منطق مشترک ربات (بدون I/O، تست‌پذیر)
bots/admin.ts     پنل سوپرادمین (فقط شناسه‌های ادمین)
bots/admin-service.ts  I/O پنل: منابع، کاتالوگ، عامل‌ها، کد اعتبار، استودیو
bots/api.ts       انتقال Bot API (تلگرام: api.telegram.org، بله: tapi.bale.ai ⚠️)
bots/dispatch.ts  ورود مشترک: ادمین ← کاربر
app/api/bot/[platform]/route.ts  وب‌هوک
scripts/bot-poll.ts | bot-set-webhook.ts | bot-daily-post.ts
```

## راه‌اندازی
1. ساخت ربات: تلگرام از @BotFather، بله از @BotFather بله. توکن را در `.env` بگذارید (`TELEGRAM_BOT_TOKEN`، `BALE_BOT_TOKEN`).
2. شناسه‌ی عددی خودتان را در `TELEGRAM_ADMIN_IDS` / `BALE_ADMIN_IDS` بگذارید (چند شناسه با کاما).
3. توسعه‌ی محلی (بدون دامنه): `npm run bot:telegram` یا `npm run bot:bale` (long-polling).
4. تولید (با دامنه‌ی HTTPS): `SITE_URL=https://… BOT_WEBHOOK_SECRET=… npx tsx scripts/bot-set-webhook.ts telegram`.
5. پرامپت روز در کانال: `npm run bot:daily -- telegram @channel` (پیش‌نمایش)، با `--send` ارسال واقعی.

## امکانات کاربر
منوی اصلی: پرطرفدارها، تألیفی‌ها، حوزه‌ها، جست‌وجو، تصادفی، پرامپت روز، زبان، راهنما. هر متن آزاد = جست‌وجو. نمایش پرامپت در تلگرام داخل بلوک `pre` (کپی با یک لمس)، در بله متن ساده. صفحه‌بندی با دکمه، `callback_data` زیر ۶۴ بایت.

## پنل سوپرادمین (`/admin`)
| کار | دستور / دکمه |
|---|---|
| آمار | 📊 |
| منابع: فهرست، تأیید/رد | 📚 |
| افزودن منبع جدید با تشخیص خودکار لایسنس | `/addsource https://github.com/owner/repo` |
| بازسازی کاتالوگ | 🔄 |
| عامل‌ها: فعال/غیرفعال، مشخصات | 🤖 |
| توسعه‌ی دستورالعمل عامل | `/agent_note <عامل> <متن>` |
| افزودن کار به صف عامل | `/run <عامل> <شرح>`، صف: 🗂 |
| کد اعتبار برای فروش دستی | `/voucher <اعتبار> [تعداد]` |
| ارسال همگانی (با تأیید) | `/broadcast <متن>` |
| ساخت پست اینستاگرام روز و دریافت فایل‌ها | 🎬 |

قواعد ایمنی: منبعی که لایسنس تجاری روشن ندارد قابل تأیید نیست؛ ارسال همگانی دو مرحله‌ای است؛ هیچ اقدام مالی خودکار نیست.
صف عامل‌ها (`content/agent-queue.json`) را جلسه‌های Claude Code یا اسکریپت‌های زمان‌بندی‌شده برمی‌دارند (سند ۰۶).
