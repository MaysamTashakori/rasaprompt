# PRD — بازار پرامپت تست‌شده (سه‌زبانه)

نام کاری: `rasaprompt` (نام برند نهایی را مالک تعیین می‌کند — ADR-002).

## مسئله
پرامپت‌های رایگان در همه‌جا هست ولی کاربر نمی‌داند کدام روی مدل امروز کار می‌کند، چقدر قدیمی است و چطور با نیاز خودش تطبیق دهد. رقبای فارسی هم‌شکل‌اند؛ بازار عربی خالی است (فاز ۱).

## کاربران
1. **فریلنسر/بازاریاب/تولیدکننده‌ی محتوا** — پرامپت آماده با نتیجه‌ی تضمین‌شده می‌خواهد.
2. **کسب‌وکار کوچک (کلینیک، املاک، خرده‌فروشی، HR)** — بسته‌ی صنعتی.
3. **توسعه‌دهنده/تیم** — API/MCP و نسخه‌بندی.
4. **سازنده‌ی پرامپت** (فاز ۸+) — فروش با کمیسیون.

## قابلیت‌ها (اولویت‌بندی)
| P | قابلیت | شرح |
|---|---|---|
| P0 | کتابخانه‌ی سئو | صفحه‌ی مستقل هر پرامپت × سه زبان؛ Lite رایگان |
| P0 | صفحه‌ی پرامپت | نمونه خروجی، نشان تست (مدل+تاریخ+نمره)، متغیرها، نسخه‌ها، نظرات |
| P0 | جست‌وجو | کلیدواژه (نرمال‌سازی ی/ک، ارقام) + معنایی (embedding) + فیلتر چندمحوره |
| P0 | خرید | تکی، باندل، سبد، پرداخت، فاکتور، کتابخانه‌ی خریدها |
| P0 | حساب | OTP/ایمیل، سفارش‌ها، لایسنس |
| P1 | اشتراک Plus/Lifetime/Team | مدیریت صورت‌حساب، صندلی |
| P1 | اجرا در سایت (BYOK) | فرم متغیر → ساخت پرامپت نهایی → اجرا با کلید کاربر (ذخیره‌ی رمزشده یا فقط مرورگر) |
| P1 | به‌روزرسانی خودکار | تست زمان‌بندی‌شده، علامت افت کیفیت، صف بازنویسی، اطلاع به خریداران |
| P2 | API + سرور MCP | جست‌وجو، دریافت، اجرای پرامپت خریداری‌شده |
| P2 | افزونه‌ی مرورگر | درج پرامپت در ChatGPT/Claude/Gemini |
| P3 | کردیت میزبانی‌شده، مارکت‌پلیس، Bounty | |

## معیار موفقیت (۹۰ روز)
≥۳۰۰ پرامپت منتشرشده و تست‌شده سه‌زبانه، ≥۱۰۰۰ صفحه ایندکس‌شده، اولین ۲۰ فروش، نرخ بازگشت وجه <۵٪.

## غیرهدف‌ها
چت‌بات عمومی، تولید تصویر میزبانی‌شده در فاز ۱، فروش محتوای بزرگسال/جعل، اپ موبایل نیتیو.

## سیاست محتوا (درس FlowGPT)
ممنوع: محتوای بزرگسال، جعل هویت/اسناد، بدافزار، آزار. بررسی خودکار با طبقه‌بند + مرور نمونه‌ای.
