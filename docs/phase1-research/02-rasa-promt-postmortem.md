# کالبدشکافی تجربه‌ی rasa-promt.ir

> **محدودیت مهم و صادقانه:** شبکه‌ی محیط اجرا به دامنه‌ی `rasa-promt.ir` (و همین‌طور archive.org) اجازه‌ی اتصال نداد و موتور جست‌وجو هم هیچ صفحه‌ای از این دامنه را برنگرداند. بنابراین این سند **بر پایه‌ی شواهد قابل مشاهده + الگوهای شکست رایج در بازار ایران** است، نه بر پایه‌ی دیدن خود سایت. برای کالبدشکافی قطعی، داده‌های بخش «چیزهایی که از شما لازم دارم» را بفرستید یا دامنه را در تنظیمات شبکه‌ی محیط مجاز کنید.

---

## الف) شواهد قطعی (بدون نیاز به دیدن سایت)

| # | یافته | اثر | شدت |
|---|---|---|---|
| 1 | **غلط املایی در دامنه: `promt` به‌جای `prompt`** | کاربر وقتی اسم را می‌شنود `prompt` تایپ می‌کند؛ گوگل ممکن است جست‌وجو را «اصلاح» کند؛ حس غیرحرفه‌ای در مخاطب فنی؛ لینک‌دهی دهان‌به‌دهان خراب می‌شود | 🔴 بالا |
| 2 | **پسوند `.ir`** | برای نسخه‌ی انگلیسی و عربی اعتماد و دسترسی بین‌المللی پایین؛ درگاه‌های خارجی و برخی سرویس‌ها با `.ir` مشکل دارند | 🔴 بالا برای EN/AR |
| 3 | **ایندکس‌نشدن در موتور جست‌وجو** (هیچ نتیجه‌ای از دامنه) | یعنی ترافیک ارگانیک تقریباً صفر؛ یا noindex، یا محتوای کم/تکراری، یا سایت در دسترس نبوده | 🔴 بالا |
| 4 | **بازار شلوغ با پیام یکسان** — حداقل ۷ رقیب ایرانی همه «اولین و معتبرترین» | بدون مزیت متمایز، رقابت فقط روی قیمت می‌شود | 🟠 متوسط |
| 5 | **برند وابسته به چتر «رسا استودیو»** (طبق موشن گرافیک مخزن: rasa-to / rasa-home / rasa-promt) | پیام برند «پرامپت حرفه‌ای» جدا از دو سایت دیگر شکل نمی‌گیرد؛ اعتبار بین سایت‌ها منتقل نمی‌شود | 🟡 کم |

## ب) فرضیه‌های محتمل (باید با داده تأیید/رد شوند)

برای هر فرضیه روش بررسی آمده؛ این بخش تبدیل به چک‌لیست ممیزی می‌شود.

| حوزه | فرضیه | چطور بررسی کنیم |
|---|---|---|
| **پیشنهاد ارزش** | فروش «فایل/متن پرامپت» بدون نمونه‌ی خروجی، بدون تست، بدون به‌روزرسانی → خریدار دلیلی برای پرداخت نمی‌بیند وقتی نسخه‌ی رایگان مشابه همه‌جا هست | آیا صفحات محصول نمونه‌ی خروجی واقعی داشتند؟ نرخ «بازدید محصول → افزودن به سبد» |
| **ترافیک** | نبود استراتژی سئو (صفحه به ازای هر پرامپت/کاربرد، کتابخانه‌ی رایگان) و اتکا به تبلیغات/اینستاگرام | Search Console: تعداد صفحات ایندکس، Impression، کلیدواژه‌ها |
| **محتوا** | تعداد کم محصول (کمتر از ~۱۰۰) یا محتوای ترجمه‌ی ماشینی/کپی | تعداد محصولات و منبع آن‌ها |
| **قیف فروش** | ثبت‌نام اجباری قبل از دیدن محصول، فرایند پرداخت چندمرحله‌ای، نبود ورود با OTP | ضبط جلسات (Clarity/Hotjar)، نرخ رهاکردن سبد |
| **قیمت‌گذاری** | قیمت تکی بالا برای کالای قابل‌کپی، نبود باندل/اشتراک/ضمانت | نسبت فروش تکی به کل، بازگشت وجه |
| **اعتماد** | نبود نماد اعتماد، نظرات واقعی، صفحه‌ی درباره‌ما و پشتیبانی پاسخ‌گو | وجود اینماد، تعداد نظر |
| **فنی** | قالب سنگین وردپرس/ووکامرس، سرعت پایین موبایل، هاست ناپایدار | PageSpeed / Core Web Vitals، Uptime |
| **عملیات** | کار دستی برای افزودن محصول، پشتیبانی، تحویل → فرسودگی تیم یک‌نفره | ساعت کار هفتگی به ازای هر بخش |
| **تمرکز** | همزمانی با دو پروژه‌ی دیگر (rasa-to، rasa-home) | زمان واقعی صرف‌شده |

## ج) درس‌ها → تصمیم‌های طراحی پروژه‌ی جدید

| شکست (محتمل) | پاسخ در پروژه‌ی جدید |
|---|---|
| دامنه‌ی غلط و `.ir` | دامنه‌ی جدید بدون غلط، `.com` یا `.ai`؛ ساختار `/fa` `/en` `/ar`؛ دامنه‌ی قدیمی با ریدایرکت ۳۰۱ به `/fa` |
| بی‌تمایزی | ۵ تمایز: «تست‌شده روی مدل X + تاریخ»، «اجرا داخل سایت»، «پرامپت با متغیر/فرم»، «به‌روزرسانی رایگان»، «افزونه‌ی مرورگر» |
| ترافیک صفر | کتابخانه‌ی رایگان چندهزارتایی (از منابع CC0 + تولید داخلی) با یک URL سئوشده برای هر پرامپت در ۳ زبان |
| فروش فایل | فروش «نتیجه»: پرامپت + نمونه خروجی + ویدیوی کوتاه + فرم متغیر + نسخه‌بندی |
| کار دستی | پایپ‌لاین تمام‌خودکار: تولید → تست → ترجمه → انتشار → پروموت → گزارش |
| پراکندگی | این پروژه محصول اصلی؛ بقیه فقط ریدایرکت/کراس‌لینک |

## د) چیزهایی که از شما لازم دارم (برای کالبدشکافی قطعی)

1. اسکرین‌شات صفحه‌ی اصلی، یک صفحه‌ی محصول، سبد/پرداخت (موبایل و دسکتاپ)
2. پلتفرم ساخت (وردپرس/ووکامرس؟ قالب؟ هاست؟)
3. خروجی Google Search Console (۳–۶ ماه) و Google Analytics یا هر آمار بازدید
4. تعداد محصولات، تعداد فروش، میانگین قیمت، کانال‌های تبلیغ و هزینه‌ی آن‌ها
5. مدت فعالیت و این‌که به نظر خودتان کجا «گیر کرد»
6. یا: افزودن `rasa-promt.ir` به Allowed domains محیط ابری تا خودم سایت را مستقیم بررسی کنم
