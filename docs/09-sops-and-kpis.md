# SOPها و KPI

## ریتم هفتگی
- **دوشنبه (۳۰ دقیقه):** گزارش `Analyst` را بخوان؛ ۳ اولویت هفته را انتخاب کن.
- **سه‌شنبه–پنجشنبه:** ساخت/بازبینی صف تأیید (≤۴۵ دقیقه در روز).
- **جمعه (۶۰ دقیقه):** بازبینی قیمت (`Pricer`)، تصمیم محتوا، نوشتن خلاصه در `MEMORY.md`.

## SOPها
1. **انتشار پرامپت:** صف `needs-human` → بررسی نمونه‌ی خروجی، لایسنس، سه زبان → تأیید.
2. **پشتیبانی:** پاسخ ≤۲۴ ساعت؛ بازپرداخت ≤$50 خودکار پس از چک شرط ضمانت؛ بیشتر → انسان.
3. **افت کیفیت پرامپت:** `stale` → بازنویسی → تست → انتشار نسخه‌ی جدید → ایمیل خریداران.
4. **مدل جدید:** افزودن به `model` → اجرای رگرسیون روی همه‌ی پرامپت‌های published.
5. **رویداد امنیتی/نشت کلید:** چرخش کلید، بررسی لاگ، ثبت در `LIMITATIONS.md`.
6. **تغییر قیمت:** فقط از PR عامل `Pricer`؛ تأیید دستی؛ ثبت ADR.

## KPI (داشبورد هفتگی)
| حوزه | شاخص | هدف اولیه |
|---|---|---|
| ترافیک | بازدید ارگانیک، صفحات ایندکس | بر اساس سناریوی پایه |
| تبدیل | بازدید→ثبت‌نام، →خرید، →اشتراک | ۳.۵٪، ۰.۷٪، ۱.۵٪ ⚠️ فرض |
| درآمد | MRR، درآمد تکی، مادام‌العمر | |
| کیفیت | میانگین نمره‌ی تست، درصد stale، بازگشت وجه | بازگشت <۵٪ |
| هزینه | LLM/ماه، هزینه‌ی هر پرامپت | ≤$100، ≤$0.35 |
| عملیات | ساعت کار انسان/هفته، اندازه‌ی صف تأیید | ≤۲۰ ساعت، ≤۲۰ مورد |
