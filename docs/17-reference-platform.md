# سایت مرجع خارجی: prompts.chat (و PromptBase برای مدل فروش)

**تصمیم (ADR-019):** مرجع محصول، **prompts.chat** است: بزرگ‌ترین کتابخانه‌ی پرامپت متن‌باز (کد MIT، محتوای CC0، پشتیبانی فارسی و عربی، قابل خودمیزبانی). مدل فروش از **PromptBase** الهام می‌گیرد (فاز ۱).
کد مرجع در محیط ساخت بررسی شد (commit `7d3f248`). به‌جای fork کامل، معماری سبک خودمان حفظ شد و قابلیت‌ها مرحله‌به‌مرحله هم‌تراز می‌شوند، چون:
1. نیازهای الزامی پروژه (FarsiUI، ایران‌محور، اعتبار مصرفی، ربات تلگرام/بله، کد اعتبار، استودیوی اینستاگرام) در آن کد نیست و ادغامشان در یک کد بزرگ خارجی برای یک نفر پرهزینه است.
2. prompts.chat وابستگی‌های سنگین دارد (Prisma، NextAuth با ورود GitHub/Google، Sentry، S3) که برای بازار ایران مناسب نیستند.
3. محتوای CC0 آن قبلاً وارد شده (۲٬۱۶۹ رکورد خام) و کد MIT آن برای برداشت تکه‌ای با ذکر منبع آزاد است.

## ماتریس هم‌ترازی
| قابلیت prompts.chat | وضعیت رسا |
|---|---|
| کتابخانه، جست‌وجو، دسته و برچسب | ✅ (۱۵ حوزه، نوع، سطح، نرمال‌سازی فارسی) |
| متغیرها و کپی | ✅ (فرم متغیر + پیش‌نمایش زنده + اجرا در سایت) |
| چندزبانه و RTL | ✅ (fa/en/ar) |
| API عمومی | ✅ پایه (`/api/prompts`) |
| ربات پیام‌رسان | ✅ (تلگرام و بله؛ در مرجع نیست) |
| اجرا با مدل و اعتبار | ✅ (در مرجع نیست) |
| حساب کاربری | ⏳ فاز بعد: OTP پیامکی (به‌جای GitHub/Google) |
| ثبت پرامپت توسط کاربران + بازبینی | ⏳ |
| نسخه‌بندی و درخواست تغییر | ⏳ (مدل داده آماده، `prompt_version`) |
| رأی، لیدربورد سازندگان | ⏳ |
| مجموعه‌ها (collections) | ⏳ (فعلاً «ذخیره‌ها» در مرورگر) |
| نظرات | ⏳ |
| جست‌وجوی معنایی | ⏳ (pgvector در اسکیما) |
| سرور MCP | ⏳ |
| Skills و Workflows | ⏳ (Skill-Smith در عامل‌ها) |

ترتیب پیشنهادی: حساب OTP ← ثبت و بازبینی پرامپت ← رأی و مجموعه ← نسخه‌بندی ← MCP.
