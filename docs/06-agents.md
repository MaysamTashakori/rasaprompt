# مجموعه‌ی عامل‌ها

هر عامل = یک نقش با ورودی/خروجی مشخص، فایل دستورالعمل در `agents/<name>.md` (به‌زودی)، و مرز اختیار. همه فقط از طریق PR/صف عمل می‌کنند؛ هیچ‌کدام کلید پرداخت یا دسترسی نوشتن مستقیم به پایگاه‌داده‌ی تولید ندارند.

| عامل | مأموریت | می‌تواند | نمی‌تواند |
|---|---|---|---|
| **Researcher** | بنچمارک رقبا، قیمت‌ها، کلیدواژه | جست‌وجو، گزارش با منبع | عدد بی‌منبع بنویسد |
| **Prompt-Author** | تولید پرامپت با متغیر و نمونه‌ی خروجی | ایجاد draft | انتشار |
| **Tester** | اجرای تست چندمدلی و امتیازدهی | فراخوانی API مدل‌ها در سقف بودجه | تغییر آستانه‌ها |
| **Localizer** | بومی‌سازی fa/en/ar | ایجاد نسخه‌ی زبانی | تغییر معنای تجاری |
| **QA-Guard** | سیاست محتوا، لایسنس، RTL/دسترس‌پذیری | رد/ارجاع به انسان | تأیید نهایی موارد مرزی |
| **Publisher** | انتشار آیتم‌های تأییدشده، sitemap | اجرای `publish.ts` | انتشار بدون نمره/تأیید |
| **SEO-Writer** | صفحات دسته، مقاله‌های مقایسه‌ای، FAQ | پیش‌نویس | انتشار مستقیم در ماه‌های اول |
| **Promoter** | محتوای شبکه‌ها و خبرنامه | پیش‌نویس و زمان‌بندی | ارسال انبوه بدون تأیید |
| **Support** | پاسخ به تیکت‌ها از پایگاه دانش | پاسخ/ارجاع | بازپرداخت > $50 بدون انسان |
| **Pricer** | تحلیل ماهانه‌ی قیمت | PR روی `pricing.json` | merge |
| **Analyst** | KPI، هزینه، هشدار | گزارش | تغییر داده |
| **Engineer** | کد و تست پروژه | PR | merge به main بدون CI سبز |

## پروتکل
1. هر عامل قبل از کار `AGENTS.md`، `LIMITATIONS.md` را می‌خواند؛ بعد از کار یک خط در `MEMORY.md` می‌نویسد.
2. خروجی ساختاریافته (JSON/Markdown) با فیلد `needs_human: true|false`.
3. شکست دوبار پیاپی → توقف و هشدار، نه تلاش بی‌پایان.
4. هزینه‌ی هر اجرا در `agent_run.cost_usd`؛ سقف روزانه اعمال می‌شود.
