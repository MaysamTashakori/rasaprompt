# سند طراحی

**جهت:** مینیمال، مدرن، آرام؛ تمرکز بر محتوا (نمونه‌ی خروجی و نشان تست).
- **رنگ:** پس‌زمینه‌ی خنثی، یک رنگ تأکیدی؛ نشان تست‌شدگی سبز؛ حالت تیره/روشن با CSS variables.
- **تایپوگرافی:** fa Vazirmatn · ar Markazi/Noto Naskh · en Geist؛ مقیاس ۱.۲۵.
- **کامپوننت:** فقط FarsiUI؛ نگاشت بلاک‌ها در `phase1-research/03-farsiui-assessment.md`.
- **RTL/LTR:** فقط کلاس‌های منطقی؛ آیکن‌های جهت‌دار با `rtl:` برعکس شوند.
- **دسترس‌پذیری:** کنتراست AA، فوکوس مرئی، `prefers-reduced-motion`.
- **حرکت:** ظریف، ≤۲۰۰ms.
- **کارت پرامپت:** عنوان، نشان مدل+تاریخ تست، نمره، قیمت/Lite، نمونه‌ی خروجی کوتاه.
