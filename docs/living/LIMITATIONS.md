# محدودیت‌ها و مجهولات (سند زنده)

## دانسته‌های ناقص
- `rasa-promt.ir` از محیط ساخت قابل دسترسی نبود؛ کالبدشکافی بر پایه‌ی الگوهاست. (نیاز: داده‌ی Search Console/اسکرین‌شات از مالک)
- قیمت و کمیسیون رقبا (⚠️) از منابع ثالث؛ باید روی سایت اصلی تأیید شود.
- مدل مالی کاملاً بر فرض است (`finance/model.py`)؛ داده‌ی واقعی ندارد.
- قیمت‌های تومانی بدون نرخ ارز روز و قیمت زنده‌ی رقبا تعیین شده‌اند.

## ریسک‌های حقوقی/مالی (نیاز به مشاور)
- واجد شرایط بودن فروشنده‌ی مقیم ایران برای پردازشگرهای بین‌المللی و تحریم‌ها.
- اینماد/شاپرک برای درگاه ایرانی؛ زمان تأیید نامعلوم.
- لایسنس پرامپت‌های واردشده (CC0 فقط با منبع و تأیید لایسنس).

## محدودیت‌های فنی
- FarsiUI تک‌نگهدارنده؛ نسخه قفل و کد در مخزن (بدون وابستگی زمان‌اجرا).
- دسترسی میزبان خارجی از ایران نامطمئن (ADR-005).
- نتایج LLM-judge خطا دارد؛ نمره‌ی تست راهنماست نه گواه.

## ظرفیت یک نفر
حداکثر ≈۲۰ ساعت/هفته، ≤۴۵ دقیقه صف تأیید در روز؛ سفارش سفارشی ≤۲/ماه.

## وضعیت ساخت
- رجیستری `farsiui.ir` از محیط ساخت بسته بود؛ `npx farsiui init` اجرا نشد. باید روی سیستم مالک اجرا و کامپوننت‌ها همگام شوند.
- DB، Auth، پرداخت، پایپ‌لاین‌ها و API/MCP هنوز پیاده‌سازی نشده‌اند (فقط طراحی).

## ایران‌محور (ADR-015..018)
- مدل‌های خارجی (ChatGPT/Claude/Gemini) برای ایران رسماً در دسترس نیستند؛ پایپ‌لاین تست باید با مدل‌هایی اجرا شود که برای مالک مجاز و در دسترس‌اند. تا آن زمان هیچ نتیجه‌ی تست واقعی وجود ندارد و seed فقط نمونه است.
- RPM و شرایط ناشر شبکه‌های تبلیغاتی ایرانی، کارمزد درگاه، الزامات اینماد برای دامنه و کد رهگیری مالیاتی تأیید نشده‌اند (⚠️).
- ترجمه‌ی فارسی ۲٬۹۹۲ پرامپت وارداتی انجام نشده؛ آرشیو فعلاً انگلیسی/عربی با UI فارسی و noindex است.
- مدل مالی ایران (`finance/model_ir.py`) صرفاً فرض است و نرخ ارز ندارد.

## وضعیت پس از نسخه‌ی کامل (۲۰۲۶-۱۰-۰۸)
- ⚠️ **امنیت:** یک کلید API در گفت‌وگو ارسال شد؛ در مخزن ذخیره نشده، اما باید **فوراً باطل و کلید تازه ساخته شود** و فقط در `.env` قرار گیرد.
- اتصال واقعی به سرویس‌دهنده‌ی مدل (مثلاً درگاه داخلی) از محیط ساخت ممکن نبود؛ مسیر چت با حالت mock تست شد.
- API بله بر اساس SDKهای شخص ثالث (پایه‌ی tapi.bale.ai) پیاده شده و با ربات واقعی آزمایش نشده؛ تلگرام هم با توکن واقعی آزمایش نشده (منطق با ۳۸ تست پوشش دارد).
- رجیستری FarsiUI (farsiui.ir) در دسترس نبود؛ کامپوننت‌ها هم‌سبک shadcn/FarsiUI دست‌نویس‌اند.
- دفترهای اعتبار/کد/کاربران ربات فایل‌محورند (تک‌نمونه)؛ برای چند نمونه یا ترافیک بالا به Postgres منتقل شوند.
- حساب کاربری، ثبت پرامپت توسط کاربران، رأی، نظرات، MCP و درگاه پرداخت هنوز ساخته نشده‌اند (docs/17).
- طبقه‌بندی حوزه‌ها قاعده‌محور است و خطا دارد؛ ۱۳۸ عنوان فارسی و ۱۶ پرامپت تألیفی کامل فارسی موجود است؛ بقیه با `npm run localize` بومی می‌شوند.
- محیط ساخت به SSH سرورها دسترسی ندارد؛ استقرار با `deploy/install.sh` توسط مالک اجرا می‌شود. رمز root سرور در گفت‌وگو ارسال شده و باید عوض شود. ساخت Docker در محیط ساخت آزمایش نشده است.
