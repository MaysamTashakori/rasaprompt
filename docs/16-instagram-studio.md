# استودیوی محتوای اینستاگرام

`npm run studio -- --daily` (یا `--slug <slug>` یا `--top 3`) برای هر پرامپت می‌سازد:

| فایل | توضیح |
|---|---|
| `caption.txt` | کپشن: قلاب، ارزش، متغیرها، فراخوان ذخیره، لینک سایت/ربات، هشتگ‌های حوزه |
| `slide-1..5.png` | کاروسل ۱۰۸۰×۱۳۵۰: جلد، کاربرد، متن پرامپت (متغیرها برجسته)، روش استفاده، فراخوان |
| `reel.mp4` | موشن‌گرافیک ۱۰۸۰×۱۹۲۰ حدود ۱۰ ثانیه: ورود برند، تیتر کلمه‌به‌کلمه، پر شدن متغیرها، اجرا، خروجی، فراخوان |
| `image-prompt.txt` | پرامپت پس‌زمینه برای مدل تصویری (اختیاری) |
| `*.html` | منبع هر قاب برای ویرایش دستی |

پیش‌نیاز محلی: `npx playwright install chromium` و `ffmpeg` (بدون ffmpeg خروجی WebM می‌ماند). فونت Vazirmatn به‌صورت محلی جاسازی می‌شود.
هویت بصری با سایت یکی است (زمینه‌ی تیره، زمردی). ویرایش قالب: `app/studio/templates.ts`.
انتشار نهایی دستی و پس از بازبینی است؛ از پنل ادمین ربات (🎬) هم قابل ساخت و دریافت است.
