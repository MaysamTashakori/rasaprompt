# عمودی‌های پریمیوم: سایت سه‌بعدی، المان‌های هوش مصنوعی، Skills

> هدف: محصولاتی با ARPU بالا که خریدار «نتیجه‌ی قابل‌دیدن» می‌گیرد. هر محصول = پرامپت‌ها + کد/پروژه‌ی کارکن + نمره‌ی تست + دموی زنده + به‌روزرسانی.
> ⚠️ بازار تأییدشده نیست؛ فقط شواهد غیرمستقیم: مهارت‌های رایگان سه‌بعدی زیاد است و بازار Skills قیمت تکی پایین ($3.99–$14.99) دارد (سند ۱۱). **دروازه‌ی اعتبارسنجی: پیش‌فروش ۳ محصول کوچک در ۲ هفته.**

## ۱) سایت‌های سه‌بعدی
**محصول:** کیت‌های «پرامپت ← سایت سه‌بعدی کارکن»: هیرو محصولی چرخان، پیکربندی‌کننده‌ی محصول، اسکرول‌تلینگ سه‌بعدی، پورتفولیو تعاملی، پس‌زمینه‌ی ذرات.
**شامل:** پرامپت‌های مرحله‌ای (برای Claude Code / Cursor / v0)، پروژه‌ی Next + React Three Fiber (MIT، تست‌شده با build)، فایل `CLAUDE.md` برای ادامه‌ی توسعه، چک‌لیست عملکرد (FPS، اندازه‌ی مدل، fallback موبایل)، دموی زنده.
**کنترل کیفیت:** `Tester` بیلد را اجرا می‌کند (Lighthouse، اندازه‌ی باندل، رندر headless) و نمره می‌دهد؛ فقط پروژه‌های سبز منتشر می‌شوند.
**قیمت 🧭:** $29 تک‌صفحه · $49 بسته‌ی ۵ قالب · $79 استودیو (۱۲ قالب + به‌روزرسانی). فارسی ≈ ضریب سند ۰۲.
**ریسک:** دارایی‌های سه‌بعدی (مدل/تکسچر) باید لایسنس تجاری روشن داشته باشند (CC0 مثل Poly Haven ⚠️ بررسی کنید)؛ هرگز مدل ناشناس.

## ۲) المان‌های هوش مصنوعی (AI Elements)
**محصول:** بسته‌های کامپوننت UI مخصوص محصولات AI: چت، نمایش استدلال/ابزار، ورودی‌های صوتی، لودینگ‌های هوشمند، شیدرهای پس‌زمینه، کارت‌های پرامپت. هر المان: پرامپت تولید + کد کامپوننت + پیش‌نمایش زنده + تغییرپذیری با متغیر.
**ساخت:** FarsiUI/shadcn به‌عنوان پایه (MIT) ← RTL-first، مزیت منحصر به بازار فارسی/عربی که رقبا ندارند.
**قیمت 🧭:** $19 تک‌بسته · $39 · $59 (۳ بسته). ⚠️ نام «AI Elements» برند یک شرکت دیگر است؛ نام تجاری خودمان را انتخاب کنید (ADR-002).

## ۳) Skills و عامل‌ها
**محصول:** بسته‌های Skill (`SKILL.md` + اسکریپت + مرجع) دسته‌بندی‌شده بر اساس کار: سئو، حقوقی-قراردادی، حسابداری، بازاریابی، توسعه، کلینیک، املاک؛ نسخه‌ی عربی/فارسی (شکاف بازار).
**تفاوت با رقبا:** تست خودکار هر Skill روی مدل‌ها، نسخه‌بندی، و گزارش «کدام مدل/نسخه» (بخش ۳ سند ۰۵).
**توزیع:** مخزن GitHub رایگان (چند Skill)، لیست در دایرکتوری‌های Skills، سرور MCP خودمان؛ نسخه‌های کامل فقط برای مشترکین Plus یا خرید.
**قیمت 🧭:** تکی $4.99–$9.99 · باندل $29–$79 · کاتالوگ کامل داخل Plus. ⚠️ بدون بازار رسمی پولی از Anthropic؛ فروشگاه‌های شخص ثالث متفاوت‌اند.
**امنیت:** Skill با اسکریپت = اجرای کد روی دستگاه کاربر → بازبینی امنیتی اجباری (`QA-Guard`)، بدون دسترسی شبکه‌ی ناشناخته، امضای هش.

## ۴) پروموت هر عمودی
- هر عمودی یک **دموی ۳۰ ثانیه‌ای خودکار** (ضبط خروجی) برای شبکه‌ها.
- صفحه‌ی «بساز با یک پرامپت» که خروجی زنده نشان می‌دهد و لینک اشتراک دارد.
- نسخه‌ی رایگان هر عمودی = ۱ قالب/المان/Skill (لیدمگنت + GitHub).
