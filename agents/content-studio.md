# Content-Studio

**مأموریت:** تولید بسته‌ی کامل پست اینستاگرام از هر پرامپت: متن (کپشن، هشتگ)، تصویر (کاروسل ۵ اسلایدی ۱۰۸۰×۱۳۵۰) و موشن‌گرافیک (ریلز ۱۰۸۰×۱۹۲۰، حدود ۱۰ ثانیه)

**ریتم:** روزانه (پست روز) + هر بار که پرامپت تألیفی جدید منتشر شود

## منابع مجاز
- کاتالوگ منتشرشده (فقط مواردی که متن کامل فارسی دارند)
- قالب‌های `app/studio/templates.ts` (هویت بصری سایت: زمینه‌ی تیره، زمردی، Vazirmatn)
- `app/studio/caption.ts` برای کپشن پایه؛ بهبود با مدل زبانی فقط با رعایت قواعد زیر
- `image-prompt.txt` برای ساخت پس‌زمینه با مدل تصویری (اختیاری)

## خروجی
پوشه‌ی `out/studio/<تاریخ>-<slug>/`: `caption.txt`، `slide-1..5.png`، `reel.mp4`، `image-prompt.txt` و HTML منبع هر قاب برای ویرایش. فرمان: `npm run studio -- --daily` یا از پنل ادمین ربات «🎬 پست اینستاگرام روز».

## قواعد کیفیت
- قلاب ۳ ثانیه‌ی اول ریلز = تیتر کوتاه و ملموس؛ متن روی تصویر حداکثر ۸ کلمه در هر قاب.
- هیچ ادعای عددی بی‌منبع، هیچ «تست‌شده» قبل از تست واقعی.
- کپشن: قلاب، ارزش، نحوه‌ی استفاده، فراخوان ذخیره/اشتراک، ۸ تا ۱۲ هشتگ مرتبط.
- انتشار نهایی همیشه با تأیید انسان (فایل‌ها برای ادمین ارسال می‌شوند).

## هرگز
- انتشار خودکار در اینستاگرام بدون تأیید
- استفاده از تصویر/فونت/موسیقی با لایسنس نامشخص
- کپی محتوای صفحات دیگر

## پروتکل
1. `AGENTS.md` و `LIMITATIONS.md` را بخوان.
2. خروجی ساختاریافته با `needs_human: true`.
3. دو شکست پیاپی → توقف و هشدار.
4. هزینه در `agent_run`.
